# TikTok + YouTube Shorts Telegram bot

MVP для Ubuntu VPS, Docker Compose, Python 3.12 и aiogram 3. Админ имеет постоянную подписку. Подписки пользователей в SQLite. Скачанные видео очищаются после отправки.

## Установка на Ubuntu VPS

1. Установите Docker Engine и Docker Compose plugin по официальной инструкции: https://docs.docker.com/engine/install/ubuntu/
2. Распакуйте архив в любую папку сервера. Откройте терминал в папке `shorts_download_bot`.
3. `cp .env.example .env` и в `.env` внесите токен @BotFather и числовой Telegram ID администратора (ADMIN_IDS). **Никому не отправляйте `.env`.**
4. `mkdir -p data && sudo chown -R 10001:10001 data`
5. `docker compose up -d --build`
6. `docker compose logs -f bot` для просмотра логов. Остановить просмотр логов: Ctrl+C (бот продолжит работать).

На сервере нужен только Docker. Python, FFmpeg и Node.js устанавливаются внутри образа, не на вашем Windows ПК.

## Команды

- `/start` — профиль, статус подписки
- `/profile` — профиль
- `/help` — справка
- `/grant USER_ID DAYS` — выдать/продлить подписку (только админ), например `/grant 123456789 30`
- `/revoke USER_ID` — отозвать подписку (только админ)
- `/users` — последние 20 пользователей (только админ)
- `/stats` — общая статистика (только админ)

Администраторы, перечисленные через запятую в ADMIN_IDS, всегда имеют доступ, независимо от базы. Обычные пользователи должны получить подписку командой `/grant`.

## Примечания и ограничения

- Принимаются публичные TikTok и YouTube Shorts URL. Загрузка не гарантирована: платформы меняют API, иногда блокируют IP серверов или требуют авторизацию. Cookies браузера не используются, поэтому личный ПК не нужен; видео, требующие авторизации, могут быть недоступны.
- `yt-dlp` автоматически выбирает форматы; FFmpeg объединяет видео и аудио, если это требуется. Node.js доступен для JS-разбора YouTube, но при изменениях YouTube могут понадобиться более новые версии yt-dlp или дополнительные компоненты.
- Размер отправляемого файла ограничен MAX_FILE_MB, по умолчанию 48 МБ. При необходимости увеличивать его нужно с учётом лимитов Telegram Bot API.
- Бот использует long polling; веб-сервер и открытые порты не нужны.
- Разрешайте загрузку только контента, на использование которого у вас есть права.
- Данные сохраняются в папке `data/` при обновлениях контейнера.
- Обновление зависимостей: `docker compose build --pull --no-cache && docker compose up -d`.

## Если ролики не скачиваются

`docker compose logs --tail=100 bot` показывает подробную серверную ошибку. Проверьте доступность ролика, не ограничен ли серверный IP, и обновите yt-dlp через пересборку. Имитация Chrome включена для TikTok. Для YouTube нет гарантированного обхода ограничений доступа.
